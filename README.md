# CodeAlpha URL Shortener

A simple URL Shortener web application developed as part of the CodeAlpha Backend Development Internship.

The application converts long URLs into short, easy-to-share links and redirects users to the original URL when the short link is opened.

## Features

- Shorten long URLs
- Generate unique short codes
- Validate URLs before shortening
- Store URL mappings in Supabase
- Redirect short URLs to the original URLs
- Handle invalid or unknown short URLs
- Simple and responsive web interface
- REST API endpoint for URL shortening

## Technologies Used

- Node.js
- Express.js
- Supabase
- JavaScript
- HTML
- CSS
- Postman
- Git & GitHub
